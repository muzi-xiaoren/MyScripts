# LINUX DO 助手

[linux.do](https://linux.do/) 的侧边悬浮框，两个功能各有一个独立的「启动 / 停止」按钮，列表地址都能直接在悬浮框里改、点「保存」就生效（存在本地，跨天保留）。

## 功能一：刷帖

默认列表是 `https://linux.do/top`。点「启动」后：

1. 回到列表页，从上到下找第一个今天还没点过的帖子，点进去；
2. 在帖子里一屏一屏往下滚。**每屏都先等视野里发言右上角的小蓝点（未读标记）消失再滚**，蓝点超过 20 秒不消失就当它不会消失，继续往下；
3. 滚到底、几秒内也没再加载出新回复，就算读完，回列表点下一个；
4. 列表里的都点过了（会自动往下加载几页），自动停止。

注意：

- 站点**只在页面可见时**才计阅读时间，跟窗口有没有焦点无关：浏览器窗口露在屏幕上（比如放在副屏）、你在用别的程序也照样计。标签页切走、窗口最小化或被完全挡住时蓝点不会消失，脚本会暂停，恢复可见后自己接着刷。
- 站点超过 3 分钟没收到滚动、或者刚加载出新楼层时不会计时，所以脚本等小蓝点时每 4 秒挪 1 像素，让它重新开始计时。
- 偶尔会有一次阅读上报被服务器拒掉（比如被 Cloudflare 挡成 403），站点自己要等 60 秒才会再报。脚本在一屏等了 12 秒还没清掉时、以及读完离开帖子前，会让站点立刻再报一次（报的是真实停留时长），离开前最多等 10 秒让它报完，避免整页跳回列表时把没报出去的丢掉。
- 回复数超过 300 的帖子会跳过（几千楼的集中帖刷不完），阈值在脚本顶部 `READ.maxReplies`。
- 刷帖运行中你自己点去别的页面，脚本不会把你拽回去；回到列表页它才接着刷。

## 功能二：领红包

默认扫 `https://linux.do/c/credit/106/l/new?subset=topics`（积分乐园 · 新话题），间隔默认 60 秒，可在地址栏旁边改（最少 20 秒）。

**什么时候扫**：

- **有新帖立刻扫**：列表页那条「查看 N 个新的或更新的话题」蓝条，是站点收到实时推送后画的。脚本直接订阅同一个推送，所以开着**任意** linux.do 页面（不用停在积分乐园列表上），积分乐园一出新帖就马上去看。帖子有新回复或被编辑也会收到推送，同一个帖子 20 秒内只重看一次，免得一排「谢谢佬」让它被反复拉取。
- **定时兜底**：打开页面或点「启动」时先扫一次，之后每隔一个间隔再扫一次，防止推送断线漏掉。

每轮把列表最前面 30 个帖子过一遍，跟上一轮比没有新回复的帖子直接跳过（推送点名的除外），有新回复的才点进去看，**只看楼主自己的发言**（读 markdown 原文，所以藏在 `<!-- -->` 注释里的也能找到），认出红包后直接调 `credit.linux.do` 的领取接口。能自动处理的写法：

| 写法 | 例子 |
| --- | --- |
| 直链 | `https://credit.linux.do/redenvelope/110243991475191808` |
| 藏在原文注释里 | `<!-- https://credit.linux.do/redenvelope/… -->` |
| 字母冒充数字 | `…/redenvelope/11o24…`（o/O→0、l/I→1） |
| 中文数字 | `…/redenvelope/11021794257403904零` |
| base64（整条链接或只编 id） | `aHR0cHM6Ly9jcmVkaXQubGludXguZG8v…` |
| base58 / hex / URL 编码 / 倒序 / ROT13 | 解开后再找一遍，最多套 3 层 |

需要动脑子的（`X 替换成我名字里的最后一个数字`、看诗猜数字之类）**不会去猜**，会列在悬浮框的「要手动解的」里，点一下打开帖子自己做；做完点左边的 ✓，这条就不再显示（跨天也不会再出现）。`hb.unsnow.org` 那类口令红包不是 credit 的，也不处理。

注意：

- 领取走的是 `credit.linux.do` 自己的登录状态，跟论坛的不是一个。**先手动去 [credit.linux.do](https://credit.linux.do) 用 LINUX DO 登录一次**；没登录时悬浮框会提示，并暂停领取。
- 第一次领取时 Tampermonkey 会弹窗问是否允许访问 `credit.linux.do`，选「总是允许」。
- 领之前先查红包详情：已领完、你已经领过、id 不存在的都不发领取请求。
- 领过的、站点明确拒绝的（领完了、已领过）红包 id 会记下来不再请求；网络错误不记，下轮再试。
- 同时开着多个 linux.do 标签页时只有一个会去扫，不会重复请求。

## 悬浮框

- 标题栏可拖动，「–」最小化成小圆球（点圆球展开），「×」关到刷新为止；位置和折叠状态会记住。
- 每块显示运行状态和今天的累计（读完几个帖子 / 领到几个红包、共多少 LDC）。
