# PT 签到 · VC-Lib

打开 [pt.vclib.online](https://pt.vclib.online/) 的任意页面时，把每日签到（领魔力）压缩成「敲 6 个字符」：

- **未签到** → 当前页正中央弹出一个小面板，里面是站点自己的验证码图（放大 2 倍并加了对比度，好认）；你照着输满 6 位就自动提交，签到完成后自动刷新页面。
- **已签到** → 什么都不做，不弹窗、不刷新。

## 为什么这个站不能全自动

VC-Lib 的签到页用的是 NexusPHP 的**经典图形验证码**：一张 `image.php` 生成的扭曲字符图 + `imagestring` 输入框 + `imagehash` 隐藏域，POST 回 `attendance.php` 才算签到。

这道题的用途就是确认「屏幕前是个人」，**脚本去识别它就等于把这道防线拆了，本脚本不做这件事**（也不接任何打码平台）。

所以分工是：能自动的全自动 —— 判断今天签没签、把验证码取到你正在看的页面、提交、判断结果、刷新页面；**唯一留给你的动作就是看图敲字符**。跟原来「跳到签到页 → 找到输入框 → 输 → 点按钮 → 手动跳回来」相比，省掉了两次跳转和翻找。

## 安装

需先安装 [Tampermonkey](https://www.tampermonkey.net/)，然后 [点此安装脚本](https://raw.githubusercontent.com/muzi-xiaoren/MyScripts/main/pt-checkin-vclib/pt-checkin-vclib.user.js)。

## 用法

打开站点任意页面 → 屏幕正中央出现面板 → 输入图中字符 → **输满 6 位自动提交**（回车也能提交）。

- **看不清**：点验证码图片换一张。图片已经放大到 300×80 并加了对比度滤镜 —— 这是为了让你看清，脚本不做任何识别。
- **输错了**：会自动换一张让你重来（`imagehash` 已被服务端消费掉，不能拿同一张重投）。
- **今天先不签**：点右上角 `×`，本次浏览器会话内不再弹（关掉浏览器重开还会提醒）。
- 面板不会抢你的输入焦点 —— 只有在你没在输别的东西时才自动聚焦。

## 配置：签到后去哪

脚本顶部的 `RETURN_TO` 默认是空串 `''`，即签到成功后原地刷新当前页。想跳到固定页面就填上：

```js
const RETURN_TO = 'https://pt.vclib.online/torrents.php';
```

另外两个开关也在脚本顶部：`CODE_LENGTH`（验证码位数，站点当前是 6，输满即自动提交；改小了也不会卡住，回车兜底）、`IMAGE_SCALE` / `IMAGE_FILTER`（验证码图的放大倍数与滤镜）。

## 原理

未签到时页面顶部是 `<a class="faqlink" href="attendance.php">[签到得魔力]</a>`，签到后 `faqlink` class 被清空、文字变成「已签到…」。脚本据此判断今天签没签（靠结构不靠文字，各站文案不同）。

需要签到时，后台拉一次 `/attendance.php`，从同一份响应里取出验证码图地址和 `imagehash`（两者必须同源同一次请求 —— 服务端是按 hash 存答案的，所以「换一张」也是重新拉整个签到页，而不是单独刷图片），渲染到面板上。你输满字符后，脚本用 `imagehash` + `imagestring` POST 回 `attendance.php`，再看返回页面里签到入口还在不在来判定成功与否（同样不看文案）。成功后写一个按天的 `localStorage` 标记兜底，保证一天只提醒一次。
