# 映幕 IMDbView

IMDb Top 250 的清爽海报墙，沿用豆影 DouView 的浅色风格。

当前版本：`1.1.4`。

## 功能

- 海报优先，榜单占满内容宽度；标题、筛选和排序保持紧凑。
- 外观设置沿用豆影的紧凑样式，浮层限制在窗口内，不挤占海报区域；支持外部点击和 Escape 关闭。
- 标题、中文片名、元数据、评分与操作文字随实际卡片宽度缩放；英文片名及中文译名分行完整显示，不做行数截断；减少文字区间距，同一行片名区域和元数据区域按实际最大高度对齐，只补齐必要间距；同一行的已看按钮统一决定并排或换行，评分徽标和评分按钮统一高度。
- IMDb 分数叠加在海报右下角，并随原站数据变化同步更新；原始评价人数保存在评分徽标说明中。原生评分按钮放在海报分数旁边；已看按钮接在年份、时长和分级后面，空间不足时自动换行。详情图标跟随中文片名末尾，没有中文片名时跟随英文名；元数据与片名间距缩小。所有控件仅调整定位，不搬动 React 管理的节点。
- 顶部导航和工具栏可整体收起；箭头在鼠标靠近或键盘聚焦时显示，触屏上始终显示，并记住收起状态。
- 提前在 document-start 注入样式，初始化期间短暂遮住原榜单，成功后立即显示美化布局；若结构不匹配，最多 2.5 秒后释放遮罩，避免长期空白。
- 收起入口加大，并与信息面板绑定显示；展开时紧贴 IMDb 导航下沿，页面滚动后仍可从上沿找到入口。
- 紧凑视图未切换成功时持续低频检查：前三次间隔至少 550ms，之后至少 2 秒；切换成功后停止重试。监听视图类名和按钮禁用状态变化，兼容原生事件处理器晚于 DOM 就绪的情况；只升级接近视口的海报，跳过脚本自身及原生加载动画的重复扫描。IMDb 原生账号请求仍可能产生加载等待，不伪造状态或隐藏加载图标。
- 首次使用默认收起顶部；鼠标靠近「IMDb Top 250」入口时，浮出完整标题、分享入口、已看进度及外观设置。移开后隐藏，面板不挤占海报空间。
- 海报宽度可调（160–360 px），卡片间距可调（8–40 px），自动保存。
- 隐藏榜单广告及右侧栏，保留原站导航、搜索和账户菜单。
- 保留原生片单、已看/未看、评分/已评分和影片详情按钮及其状态。
- 原片名旁显示对应中文名，例如「The Shawshank Redemption · 肖申克的救赎」，原名及影片链接保留。
- 保留 IMDb 原生排序、筛选；观看进度读取原站数据，文字与进度条分行显示并跟随更新。
- 分享使用独立浅色浮层，固定在分享按钮旁，不改变顶部尺寸；提供 Facebook、X / Twitter、邮件分享和复制链接，打开平台页面后由用户完成分享。
- 海报完整显示；较大图片加载失败时回退到原图。
- 仅在 `https://www.imdb.com/chart/top/` 生效，支持查询参数。

## 安装

安装 [Tampermonkey](https://www.tampermonkey.net/) 后，点击 [安装 IMDbView](https://raw.githubusercontent.com/muzi-xiaoren/MyScripts/main/imdbview/imdbview.user.js)。之后打开 IMDb Top 250 即可。

Chrome 若已启用脚本但不生效，请在扩展详情页开启「允许用户脚本」，然后刷新页面。

也可以手动安装：

1. 在 Tampermonkey 中新建脚本。
2. 用 [imdbview.user.js](./imdbview.user.js) 的完整内容替换默认模板并保存。
3. 打开 IMDb Top 250 页面，将鼠标移到上沿中央的入口，在浮出的面板里点击「外观设置」调整大小和间距。

脚本会切到 IMDb 原生紧凑视图，再通过样式呈现海报墙。登录后使用 IMDb 的原生按钮管理观影状态；脚本不额外获取或保存账户数据。

## 中文片名

通过 [Wikidata](https://www.wikidata.org/) 的 IMDb ID 字段精确匹配，不使用自动翻译或名称模糊匹配。优先大陆、简体中文名称，其次其他中文名称；不同地区译名可能与豆瓣不同。没有对应名称或匹配不唯一时只显示原名。

脚本仅向 `query.wikidata.org` 发送公开的影片 ID，不携带 IMDb 的登录 Cookie。每批最多 50 部，依次查询，查询失败重试一次；成功结果缓存 30 天，查不到的结果缓存 7 天。获取失败时保留原界面，下次打开页面再尝试。更新已安装脚本时，油猴会提示新增的跨域请求权限。

已用缓存中文片名验证长英文及中文名称完整显示；Wikidata 实际请求仍需实站验证。

`1.1.4` 追加隔离检查已确认长片名未裁切、海报评分显示及动态更新正常，原生评分、已看和详情节点及点击事件仍然保留；评分按钮位于海报内，详情图标不与元数据重叠。另已验证 document-start 在根节点尚未建立时安全初始化、遮罩正常释放、入口与面板同步显示。原站进入时账号请求的实际耗时仍待实站验证。
