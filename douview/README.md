# 豆影 DouView

豆瓣电影 Top250 的油猴美化脚本，采用清爽绿色海报墙。

当前版本：`1.2.0`。

## 功能

- 将原列表改为圆角海报卡片，保留电影标题、别名、排名、评分、评价人数和短评。
- 海报完整显示，不裁切；卡片使用紧凑信息层级：主片名最多两行、不预留空白标题行，年份与最多两个类型一行显示；原名收入详情。
- 标题、评分、辅助文字和操作按钮的字号随实际卡片宽度调整，设置最小与最大字号；调整海报大小或窗口宽度时同步变化。
- 采用 C 方案：评分叠加在海报右下角，可播放标记位于右上角；下方直接显示豆瓣原站的一句话短评，最多两行，长内容可悬停或展开「详情」查看全文。原站没有短评时不补造内容。
- 「详情」与「想看 / 看过」等原生操作紧凑并排；展开后保留完整片名、原名、别名、地区、类型、短评、原始评价人数及演职员信息。
- 隐藏右侧广告、App 二维码推广和导航中的年度推广图。
- 保留豆瓣原生的「想看」「看过」等操作：原页提供几个就显示几个，不伪造观影状态。
- 保留「可播放」标记、未看筛选、电影搜索和原生分页。
- 顶部默认收起，不常驻显示榜单标题。鼠标移入上沿中央或键盘聚焦时显示原生「我没看过的」筛选文字及原站数量，可直接点击文字切换；旁边的小箭头展开或收起搜索与导航，并记住状态。触屏直接显示入口。
- 搜索使用紧凑圆角输入框；「导航与账号」浮层自动限制在窗口内，保留原站导航链接和账号操作。
- 展开顶部后，「外观设置」可调节海报目标宽度（160–360px）和卡片间距（8–40px），并恢复默认。点击外部或按 Escape 关闭浮层。
- 分页下方的「共 N 条」后可选择每页 25、50、100 或 250 条，默认 25 条，并记住选择。更改条数时回到第一页；未看筛选参数保留，分页按选择的条数重排。
- 超过 25 条时顺序读取原站后续分页并显示加载进度；加载失败保留已显示内容，可点击「重试加载」。末页或筛选结果不足所选条数时只显示实际电影。
- 登录后海报左下角显示「我的评分」五星，点击即可打分；未看过的电影会同时标记为看过。打分沿用豆瓣收藏弹窗的表单：先读取已有短评、标签和仅自己可见设置，只替换星级，不勾选同步广播。
- 「GitHub 同步」：展开顶部后填写 GitHub Token、仓库地址，以及可选的分支和文件路径（默认 `movies/douban`），点击上传后读取账号下全部「看过」记录，按我的评分（5 星）从高到低排名，同分并列；未评分的排在最后。每次上传新建一组带本地时间戳的文件，例如 `movies/douban-2026-10-10-203015.json` 和 `.md`，不覆盖旧文件。
- 设置保存在油猴存储中，刷新和翻页后保留。

海报目标宽度决定一行可以容纳多少张卡片，实际宽度会随窗口自动调整；海报越大，一行列数越少。默认目标宽度 240px、间距 22px。

展开顶部后可使用原生搜索、「导航与账号」及「外观设置」菜单；未看筛选可在上沿直接点击，介绍文案移至页尾，首屏优先展示海报。

## 安装

在 Tampermonkey 中新建脚本，将 [douview.user.js](./douview.user.js) 的全部内容粘贴进去并保存，再打开或刷新 <https://movie.douban.com/top250>。

Chrome 中需要在 Tampermonkey 的扩展详情页开启「允许用户脚本」。

也可以使用 [安装链接](https://raw.githubusercontent.com/muzi-xiaoren/MyScripts/main/douview/douview.user.js)，并由脚本管理器检查更新。

## 范围与说明

仅作用于 `movie.douban.com/top250` 及其分页、筛选参数，不修改电影详情页。脚本在原页面上调整样式和信息排列，收藏操作仍由豆瓣处理；未登录时不会补造收藏按钮。

隐藏广告是展示层处理，不保证广告网络请求被拦截。停用脚本并刷新页面即可恢复原始界面。

`1.1.5` 已通过 JavaScript 语法检查及无头 Chrome 隔离页面验证：320px、390px、768px、1280px 无横向溢出，搜索按钮未被裁切，导航浮层未被遮挡且位于窗口内，悬停入口与原生筛选点击、顶部折叠及展开、设置浮层边界、Escape 关闭、设置写入及恢复默认、完整信息展开、原节点与点击事件保留、动态多操作按钮均通过；未发现运行错误。隔离页面按豆瓣结构搭建，使用占位海报和模拟 GM 存储。内置浏览器与 Edge 实站复测均因浏览器控制读取超时未完成，尚未验证真实页面样式兼容、油猴刷新/翻页持久化及真实收藏提交。

`1.0.0` 的历史验证：在 Chrome + Tampermonkey 实页确认海报墙、真实海报、可播放标记和推广区域隐藏；在豆瓣未看筛选页确认原站双操作结构。此前内置浏览器隔离验证覆盖原站样式及 20 张实际海报、响应式布局、设置持久化和动态操作；这些历史结果不代表 `1.1.0` 已完成实站复测。

字号缩放已在隔离页面验证：海报目标宽度 160px、240px、360px 时，标题、评分及辅助文字的实际字号均同步增大；最大字号受限，未出现横向溢出。

分页已通过隔离响应测试：250 条完整加载、50 条分页、100 条设置下末页仅 50 条、未看筛选 73 条和 20 条、失败后的部分内容保留及重试，均无重复电影，追加卡片正常美化。真实豆瓣批量加载及追加卡片的账号操作尚未完成实站复测。

## 我的评分与 GitHub 同步

海报上的星级来自「看过」列表缓存：缓存缺失或超过 7 天时在后台重新读取一次，每次上传也会刷新。「看过」列表每页 30 条，请求间隔 0.8 秒；如果豆瓣要求验证，读取会停止并提示稍后再试，脚本不会处理验证码。列表模式只提供中文片名，JSON 含排名、豆瓣 ID、片名、年份、我的评分、标记日期和链接，Markdown 为同样内容的排行表。

Token 以明文保存在油猴存储中，建议使用只授权目标仓库、只开放 Contents 读写的 fine-grained token。上传请求只发往 `api.github.com`，不携带豆瓣 Cookie；首次上传时油猴会请求跨域权限。

`1.2.0` 验证：通过本地代理加载真实 Top250 页面及公开账号的真实「看过」列表（218 条中实际显示 216 条，单页不足 30 条时翻页正确，无重复），验证了星级回显、打分提交字段（保留短评、标签和可见性，去掉同步选项）、上传面板定位、时间戳文件名、自定义分支与路径。之后在已登录的真实账号上验证：从「我的电影」页识别账号，读取全部 254 条「看过」记录，无遗漏；读取真实收藏表单，并以原星级重新提交一次，豆瓣返回成功，星级、短评、标签和可见性保持不变，标记日期未被刷新。GitHub 写入为模拟接口。
