# 豆影 DouView

豆瓣电影 Top250 的油猴美化脚本，采用清爽绿色海报墙。

当前版本：`1.1.0`。

## 功能

- 将原列表改为圆角海报卡片，保留电影标题、别名、排名、评分、评价人数和短评。
- 海报完整显示，不裁切；卡片使用紧凑信息层级：主片名最多两行、原名一行省略、年份与最多两个类型一行显示。
- 评分与精简评价人数并排显示，例如「334.9万评价」；悬停可查看原始人数。完整片名、别名、地区、类型、短评及演职员信息保存在「影片信息」展开区。
- 隐藏右侧广告、App 二维码推广和导航中的年度推广图。
- 保留豆瓣原生的「想看」「看过」等操作：原页提供几个就显示几个，不伪造观影状态。
- 保留「可播放」标记、未看筛选、电影搜索和原生分页。
- 上沿中央「豆瓣电影 Top 250」入口参考 IMDbView：首次默认收起搜索与导航，点击展开或收起，并记住状态；悬停或键盘聚焦显示标题与「筛选与外观」浮层，触屏可点击入口使用。
- 「筛选与外观」可调节海报目标宽度（160–360px）和卡片间距（8–40px），并恢复默认。点击外部或按 Escape 关闭浮层。
- 设置保存在油猴存储中，刷新和翻页后保留。

海报目标宽度决定一行可以容纳多少张卡片，实际宽度会随窗口自动调整；海报越大，一行列数越少。默认目标宽度 240px、间距 22px。

展开顶部后可使用原生搜索及「导航与账号」菜单；未看筛选与外观控制使用浮层，介绍文案移至页尾，首屏优先展示海报。

## 安装

在 Tampermonkey 中新建脚本，将 [douview.user.js](./douview.user.js) 的全部内容粘贴进去并保存，再打开或刷新 <https://movie.douban.com/top250>。

Chrome 中需要在 Tampermonkey 的扩展详情页开启「允许用户脚本」。

也可以使用 [安装链接](https://raw.githubusercontent.com/muzi-xiaoren/MyScripts/main/douview/douview.user.js)，并由脚本管理器检查更新。

## 范围与说明

仅作用于 `movie.douban.com/top250` 及其分页、筛选参数，不修改电影详情页。脚本在原页面上调整样式和信息排列，收藏操作仍由豆瓣处理；未登录时不会补造收藏按钮。

隐藏广告是展示层处理，不保证广告网络请求被拦截。停用脚本并刷新页面即可恢复原始界面。

`1.1.0` 已通过 JavaScript 语法检查及无头 Chrome 隔离页面验证：320px、390px、768px、1280px 无横向溢出，顶部默认折叠及展开、设置浮层边界、Escape 关闭、设置写入及恢复默认、完整信息展开、原节点与点击事件保留、动态多操作按钮均通过；未发现运行错误。隔离页面按豆瓣结构搭建，使用占位海报和模拟 GM 存储。本次未能直连豆瓣，尚未验证真实页面样式兼容、油猴刷新/翻页持久化及真实收藏提交。

`1.0.0` 的历史验证：在 Chrome + Tampermonkey 实页确认海报墙、真实海报、可播放标记和推广区域隐藏；在豆瓣未看筛选页确认原站双操作结构。此前内置浏览器隔离验证覆盖原站样式及 20 张实际海报、响应式布局、设置持久化和动态操作；这些历史结果不代表 `1.1.0` 已完成实站复测。
